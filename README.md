# 安卓逆向实战

Android 逆向工程的项目归档：两条签名还原路线（unidbg 仿真 / 真机 Xposed+RPC）、
可复用的技能文档，以及若干目标 App 的分析脚本。

## 目录

| 目录 | 内容 |
|---|---|
| `skills/` | 可复用的逆向技能（通用 APK 逆向、抖音专项、技能创作工具） |
| `unidbg/` | unidbg 仿真路线：签名器 Java 服务 + Python 客户端 |
| `Xposed/` | 真机路线：Xposed 模块 + Sekiro RPC 客户端 |
| `frida-hook/` | Frida 脚本集合（脱壳、hook、反调试绕过） |
| `main.py` / `fix_dex.py` | 辅助脚本 |

## 技能（skills/）

| 技能 | 作用 |
|---|---|
| `apk-reverse/` | 通用入口：战场勘察 → **证据清单判定路线** → 交付纪律 |
| `douyin-reverse/` | 抖音专项：六神签名、unidbg 契约、两条路线、踩坑实录 |
| `skill-creator/` | 技能创作与评估工具 |

核心方法论：**先判断能不能纯算还原**（六条证据：crypto 常量扫描、锚点扫描、
静态可达性、JIT 判定、JNI 依赖度、密钥来源），再与用户确认走哪条路线并给出工时。

## 两条路线对比

| 维度 | unidbg 仿真 | 真机 + Xposed + RPC |
|---|---|---|
| 依赖手机 | 不需要 | 必须常开 |
| 单次签名 | 约 48 ms | 约 5-20 ms |
| 并发 | 靠实例池，随设备数扩展 | 单机串行 |
| 设备身份 | 可自主注册 | 用真机身份 |
| 适用 | 批量采集、离线服务 | 快速验证、少量数据 |

## 关于本仓库

**不包含**：APK、反编译产物、厂商 `.so`、设备身份文件、抓取数据。
这些内容体积大、涉及版权，且设备身份属于敏感信息，均通过 `.gitignore` 排除。

仓库只保留可复用的**源码、脚本和文档**。
